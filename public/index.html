ONE QUESTION · THREE PASSES

See what changes when the method changes.

Choose GPT, Grok, or Gemini. The app sends the same question to that model twice—first with ordinary formatting instructions, then with the Open Inquiry Constitution added—and asks the same model to compare the responses.

What is Open Inquiry? It is a method for improving how questions are investigated, not a set of required conclusions. This app makes the method inspectable: you can compare outputs, inspect the exact prompts, trace Constitution references, and export the run.
