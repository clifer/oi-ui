# Changelog

Notable changes to the Open Inquiry reference app are recorded here.

## [0.4.0] - 2026-09-19

### Added

- public-project license, attribution, contribution, conduct, and security docs;
- GitHub issue and pull-request templates;
- automated dependency updates and CI;
- reproducible npm dependency lockfile generation;
- public-deployment request, daily, and provider usage controls;
- deployment guidance and provider-independence disclaimer.

### Security

- documented server-side key handling and key-rotation guidance;
- expanded ignore rules for local environment, database, and credential files;
- scanned repository history for common OpenAI, xAI, Gemini, and API-key
  assignment patterns before public release hardening.

## [0.3.1] - 2026-09-19

- Added provider-specific model selection and configurable model lists.

## [0.3.0] - 2026-09-19

- Added reproducibility metadata, prompt inspection, Markdown export, raw view,
  article links, reruns, examples, and opt-in browser-local experiment history.
